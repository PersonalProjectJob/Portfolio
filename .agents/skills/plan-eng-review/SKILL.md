# Lệnh: `/plan-eng-review`

**Mục tiêu:** Đánh giá và thiết kế Kiến trúc Kỹ thuật (Engineering Architecture).

Khi người dùng gọi lệnh này, AI sẽ:
1. Đóng vai một Tech Lead / Principal Engineer.
2. Xây dựng bản nháp kiến trúc hệ thống (State management, Data flow, API integrations, File structure).
3. Đánh giá Tech Stack hiện tại xem có phù hợp với MVP hay không.
4. Dự đoán các rủi ro kỹ thuật (Technical Debts, Performance bottlenecks) và đề xuất giải pháp.
