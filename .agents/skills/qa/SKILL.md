# Lệnh: `/qa` (hoặc `/dogfood`)

**Mục tiêu:** Kiểm thử chất lượng sản phẩm.

Khi người dùng gọi lệnh này, AI sẽ:
1. Đóng vai một QA Engineer hoặc End User (Target Audience).
2. Tự động soát lỗi trên giao diện (Console errors, Responsive issues trên Mobile/Tablet).
3. Kiểm tra hiệu năng (Lighthouse metrics giả định).
4. Lên danh sách các lỗi (Bugs) cần fix ngay lập tức trước khi Launch.
